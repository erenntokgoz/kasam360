## C06 lisans ve eşitleme davranışı

Mevcut IPC adları değişmedi: `refresh_license` kurulum tamamlandıysa önce yerel `app_setup.tenant_id` ile cihaz aktivasyonunu idempotent yürütür, sonra tenant V2 lisansını alır ve imza/tenant/device/süreyi doğrulayıp `device_license.token` alanına yazar. `get_license_status` ağ çağrısı yapmadan V1 veya V2 belgeyi okur; V2 tenant'ı mevcut kurulumla eşleşmezse özellik listesi kapalı ve durum `INVALID` olur. V1 token/satırları geçiş sırasında korunur.

`cloud_sync` komutları tenant yolunu IPC argümanından almaz: lisans hesabı, kurulum tenant'ı ve `local_device_identity` birlikte doğrulanır. Farklı tenant kimliği varsa gönderim/çekme/geri yükleme fail-closed durur. HTTP adaptörü yalnız `/api/desktop/sync/tenants/{tenantId}/...` çağırır. UI store `LicenseStatus.tenantId` alanını yeni V2 yanıtta okuyabilir; bu alan eski V1 yanıtlarda yoktur.
